# Ideas

My brain dump for DIY projects such as soldering stations, sensors, remotes, homelab and more

I get way more ideas than I have time (or money) for. This repo is where they land so I do not forget them. Some will turn into actual projects and some will stay here forever and thats fine.

---

## How it works

- **Every idea is an [issue](../../issues)** Quick to add, easy to comment on and update over time
- **Progress is tracked on [Project Board](../../projects)**
- **When an idea grows into a real project** It gets its own repo and the issue links to it

---

### Status flow

```
💭 Idea  →  ⏭️ Next  →  🔨 In progress  →  ✅ Done
                                ↓
                           ⏸️ Paused
```

---

## Labels

| Label | Meaning |
|---|---|
| `idea` | Just a thought, nothing started yet |
| `in-progress` | Actively working on it |
| `paused` | Started, but on hold for now |
| `done` | Finished (or good enough) |
| `electronics` | Circuits, PCBs, soldering |
| `3d-print` | Involves designing or printing parts |
| `software` | Code, firmware, apps |
| `homelab` | Self-hosting, Home Assistant, servers |
| `cheap` | Can be done with stuff I already have |
| `needs-parts` | Requires buying components first |

## Areas I usually tinker with

- **Electronics** - ESP32, nRF52840, sensors, power electronics, custom PCBs
- **Home automation** - Home Assistant, ESPhome, MQTT, Zigbee
- **3D printing** - enclosures, mounts and workshop organization on my modified Ender 5 Pro
- **Homelab** - self-hosted services, Docker, Traefik
- **Software** - whatever the project needs

## Adding a new idea

1. Open a [new issue](../../issues/new/choose) using the **Idea** template
2. Fill in **what**, **why** and the **first step**
3. Pick a few labels
4. Done, back to whatever I was doing
